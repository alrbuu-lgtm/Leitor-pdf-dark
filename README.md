# Leitor PDF Dark

Aplicativo Android gratuito para leitura de PDFs offline, com modo escuro e sem assinaturas.

O build de teste será disponibilizado como artefato do GitHub Actions após o envio do código.

## Novidades 1.4

- Rolagem vertical entre as páginas, com pré-visualização da anterior e da próxima sem carregar o documento inteiro na memória.
- Deslize para cima/baixo e movimento com inércia; zoom por pinça permanece disponível.
- Contador flutuante de página atual / total (ex.: 5 / 80), inclusive com comandos ocultos e em modo horizontal.
- Tradução EN → PT preservada na página atual. As páginas vizinhas podem aparecer no idioma original até receberem a tradução ao entrarem no centro da tela.
